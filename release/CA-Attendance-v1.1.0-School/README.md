# CA Attendance v1.1.0 - School Bundle

This is the local package for the school's private Android rollout. Share the APK only through the school's official, trusted distribution location.

## Contents

| File | For | Purpose |
|---|---|---|
| `CA-Attendance-v1.1.0.apk` | Android users | Signed app installer; install over an existing copy for updates |
| `Teacher-Quick-Start.pdf` | Teachers | Sign up, class access, attendance, reports, and support |
| `Admin-Guide.pdf` | Administrators | Role access and current administration workflows |
| `Technical-Release-Record.md` | Deployment personnel | Version, app ID, build results, APK size, and SHA-256 |
| `README.md` | Everyone | Package contents and starting point |

New signups start with the teacher (`user`) role. An administrator must assign teachers to classes. A newly signed-up administrator must ask the developer to grant the administrator role.

Before broad distribution, complete school-side checks for production accounts and assignments, Firestore rules and indexes, the official HTTPS update URL, and installation on a real Android device. The APK and documents are prepared locally; this bundle has not been uploaded or distributed.
