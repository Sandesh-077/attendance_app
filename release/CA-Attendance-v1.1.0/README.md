# CA Attendance v1.1.0
## School Deployment Package

This package contains the signed Android APK and guides for the school's initial private rollout.

| File | Purpose |
|---|---|
| `CA-Attendance-v1.1.0.apk` | Install or update the Android app |
| `Teacher-Quick-Start.md` | Day-to-day instructions for teachers |
| `Admin-Guide.md` | Current administrator workflows |
| `Installation-Guide.md` | Android APK installation and updates |
| `Whats-New-v1.1.md` | User-facing release notes |
| `Deployment-Checklist.md` | Rollout tasks for deployment personnel |
| `Technical-Release-Record.md` | Build identity, results, and checksum |

Teachers should start with the **Teacher Quick Start Guide**. Administrators should read the **Admin Guide**. Technical and deployment personnel should use the **Installation Guide**, **Deployment Checklist**, and **Technical Release Record**.

Distribute the APK only from the school's official HTTPS location. Complete the remaining checklist items before full rollout.
