# CA Attendance — Android Installation Guide

1. Obtain **CA-Attendance-v1.1.0.apk** from the school's official distribution location and open it on your Android device.
2. If Android displays an **Install unknown apps** warning, allow installation only for the trusted app you used to open the file (for example, the school's approved browser or file manager).
3. Return to the installer, tap **Install**, then open **CA Attendance** and sign in with your school-provided account. You may disable the installation permission again afterward.

If CA Attendance is already installed, normally **update the existing app** by installing the new school-provided APK over it. Avoid uninstalling first: uninstalling may clear local application data and preferences. Account and attendance data backed by Firebase are held server-side, but unnecessary reinstalling can still disrupt local settings.

CA Attendance checks its remote update configuration. When an update is available, use the app's **Update** action and follow the school's official HTTPS distribution location. Do not install APKs from unofficial links. If installation fails, contact the school's technical support contact.
