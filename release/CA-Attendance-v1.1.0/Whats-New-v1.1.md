# CA Attendance V1.1
## What's New

### Attendance
- Improved attendance controls across different screen sizes.
- Fixed student-name display in Attendance History.
- Improved reporting controls on smaller screens.
- Added a confirmation before leaving attendance with unsaved marks.

### Student Records
- Student records now show report history and resolution status.
- Improved the Add Student form and made consecutive student entry faster.

### Search
- Added student-name search to the teacher Class Roster.
- Simplified administrator student search.

### Reports
- Improved student report visibility.
- Added configurable detail requirements for report options.
- Improved severity selection on smaller screens.

### Dashboard & Navigation
- Added personalized welcome messages.
- Simplified dashboard information and navigation.
- Back from a main section now returns to the dashboard; Profile appears above App Info in the menu.

### Classes
- Improved the appearance of archived classes.
- Adding a student from a class automatically uses that class.

Additional usability improvements, bug fixes, and stability improvements.
