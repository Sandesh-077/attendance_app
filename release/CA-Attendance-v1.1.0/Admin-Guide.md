# CA Attendance — Administrator Guide

Version 1.1.0

## Sign up, role access, and dashboard
If you sign up in the app, the account initially receives the teacher (`user`) role. Contact the developer to give that account the administrator role; signing up alone does not grant administrator access. Once your administrator role is active, sign in. The dashboard welcomes you and links to **Attendance**, **Classes**, **Students**, **Profile**, **Teachers**, and **Reports**. The navigation drawer also opens **App Info** and provides **Log out**.

## Classes
Open **Classes** to see active and archived classes. Tap **Add Class** to enter grade, section, and academic year. Open a class to edit it, view its students, review attendance and history, or manage its report options. Use **Archive Class** when a class is no longer active; archived classes remain visible in the archived list and can be unarchived. Archiving retains records rather than deleting them.

## Students
Open **Students** to search by student name, filter by class, and switch between active and archived students. Tap **Add Student**, enter a name and roll number, and select an active class. After saving, the form clears the name and roll number so you can enter another student in the same class; tap **Done** when finished. Opening **Students** from a class fixes that class in the add form. Open a student to edit active records, view attendance history and report history, or archive the student. Archived student records remain available; editing an archived student is disabled. Students do not have CA Attendance login accounts.

## Teachers and assignments
Open **Teachers**, select a teacher, and use **Assign Class** to choose an active, unassigned class for that teacher. An optional subject can be recorded. Use the remove-assignment control when an assignment ends. Teachers should only access classes assigned to them. Teacher accounts must already exist before they appear here; this screen lists and assigns existing teacher accounts.

## Attendance and history
Open **Attendance**, select a class, and review or mark attendance for the selected date. Set each student's status to **Present**, **Absent**, or **Late**, then save and confirm. An administrator can open a class's **Attendance** screen to review and correct daily attendance where authorized. **Attendance History** shows class records by date and individual student history is available from student details. Archived records remain part of history.

If you leave the attendance screen or change dates with unsaved marks, the app asks whether to continue or discard the changes. Back from a main navigation section returns to the dashboard.

## Student reports
Open **Reports** for reports needing attention or historical reports. Review counts, filter by class, and open a student's report history. Individual student details also show reports and their resolution status. A report can be resolved with a resolution note. Resolved reports remain historical records; resolving does not erase the original report.

## Report options
From **Classes** → a class → **Report Options**, review built-in and custom reasons. Add or edit an option, choose its category, and set **Require teacher details** when an explanation must be supplied. Custom options can be disabled. Serious reports require an explanation in the reporting form. Options for archived classes are read-only.

## Profile, app information, and updates
**Profile** shows account name, email, and role, and offers name and password changes. **App Info** displays the installed version and build number. Tap **Check for Updates** to check the remote release configuration; if a newer version is available, **Update** opens its configured HTTPS link. Use only the school's official distribution location for production APKs.
